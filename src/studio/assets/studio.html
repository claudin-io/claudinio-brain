            Reading the graph

            A node is an entity. An edge is a fact whose object is another entity — so an edge is bitemporal too, and one that ended is drawn as a dashed ghost rather than deleted. A fact that was retracted was never true, so it is hidden unless you ask for it, and struck through when shown.

            now is the open fact, which is not the same as “true at this instant”: a fact dated in the future is open but not yet true, and the studio rings it in violet so the difference is visible.
